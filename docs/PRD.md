# 剧析 DramaInsight V0.2 精简 PRD

## 产品定位

面向短剧观众的单集内容理解工具。用户上传一集合法视频后，系统生成可跳转的剧情节点、高光片段和本集观看建议，帮助用户快速决定看哪里、是否继续追。

## 核心用户

短剧重度观众，主要需求是快速定位剧情推进与高光片段，而不是搜索片源或获得整剧剧透。

## MVP 范围

1. 上传 MP4、MOV、AVI 或 MKV 单集视频，最大 100 MB。
2. 在整段视频上均匀抽取最多 20 帧，并保留真实时间戳。
3. 输出零个或多个剧情节点，不强制凑齐所有类型。
4. 输出零个或多个高光片段，并提供置信度。
5. 输出只针对当前视频的观看建议。
6. 在播放器中点击节点或高光片段后跳转。
7. 记录用户对每条结果的“有用/不准”反馈。

## 明确不做

- 剧名搜索、第三方视频抓取和片源播放
- 整剧分析、烂尾预测和“哪些集可以跳过”
- 社区、分享、个性化推荐和创作者工具
- 实时视频流分析
- 自训练模型

## 核心流程

```text
选择本地视频
  -> 校验格式与大小
  -> 创建分析任务
  -> FFmpeg 全片均匀抽帧
  -> 多模态模型结构化分析
  -> Pydantic 校验与时间戳归一化
  -> 播放器、时间线和观看建议展示
  -> 用户反馈
```

## 验收标准

- 前端生产构建和后端导入检查通过。
- 缺少 FFmpeg 时，健康检查返回 `degraded` 并明确指出缺失项。
- 无效格式、空文件和超限文件得到明确错误。
- 1 至 3 分钟视频的采样画面覆盖开头、中段和结尾。
- 模型结果必须是合法 JSON，时间戳位于视频时长内。
- 点击任一时间标记后，播放器跳转到对应位置并开始播放。
- 分析完成和失败后不残留视频或抽帧文件。
- 评测采用一对一匹配的 Precision、Recall、F1，不填写未经实测的指标。

## 后续版本

- 接入 ASR 或字幕提取，补充台词信息。
- 使用 Redis/Celery 管理持久化任务。
- 建立 20 至 30 集授权评测集并记录真实基线。
